# Freqtrade量化交易监控脚本

## 功能概述

自动监控Freqtrade量化交易程序，确保服务稳定运行。

### 主要功能

1. **进程监控**
   - 检测量化进程是否运行（PID文件 + 进程名双重检查）
   - 异常则自动重启（最多3次）
   - 启动失败发送邮件告警

2. **智能日志分析**
   - 使用大模型智能识别日志类型（正常/网络异常/其他异常）
   - 增量分析日志（记录上次读取位置）
   - 定长循环数组存储（1000条）

3. **网络异常处理**
   - 统计最近24小时异常次数和正常次数
   - 条件：`网络异常次数 > 正常次数 && 正常次数 < 5`
   - 发送邮件告警（每天一次）

4. **其他异常处理**
   - 调用大模型分析异常原因
   - 生成解决方案并保存到文档
   - 条件：24小时异常次数 > 10次
   - 发送邮件告警（每天一次）

5. **无响应检测**
   - 检测超过15分钟无日志输出
   - 发送邮件告警（每天一次）

## 使用方法

### 1. 手动运行

```bash
python3 /opt/git/freqtrade/check/check_freqtrade.py
```

### 2. 配置定时任务

```bash
bash /opt/git/freqtrade/check/setup_cron.sh
```

定时任务：每10分钟执行一次
```
*/10 * * * * /usr/bin/python3 /opt/git/freqtrade/check/check_freqtrade.py >> /opt/git/freqtrade/check/logs/cron.log 2>&1
```

### 3. 查看监控日志

```bash
tail -f /opt/git/freqtrade/check/logs/check_$(date +%Y%m%d).log
```

### 4. 查看Cron日志

```bash
tail -f /opt/git/freqtrade/check/logs/cron.log
```

**邮件内容**：

**触发条件**：`网络异常次数 > 正常次数 && 正常次数 < 5`

## 大模型分析功能

### 日志类型识别

**提示词**：
```
这是一个Freqtrade量化交易程序的日志片段。

请分析这段日志属于哪种类型：
- 正常：程序正常运行，执行交易策略
- 网络异常：网络连接问题、API超时等
- 其他异常：代码错误、配置错误等

日志内容：
{log_content}

请直接返回类型名称（正常/网络异常/其他异常）。
```
