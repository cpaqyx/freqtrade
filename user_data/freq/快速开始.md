# HighFreq5mStrategy 快速开始指南

## 🎯 5分钟快速上手

### 步骤1：检查数据
```cmd
# 查看5分钟数据是否已下载
dir user_data\data\binance\futures\*-5m-*.feather
```

应该看到9个文件（9个币种的5分钟数据）。

---

### 步骤2：运行回测

#### 推荐：先测试BTC/ETH
```cmd
.\user_data\freq\backtest_be.bat
```

#### 或测试全部9个币种
```cmd
.\user_data\freq\backtest_all.bat
```

---

### 步骤3：参数优化

#### BTC/ETH参数优化（1000次测试）
```cmd
python freqtrade/main.py hyperopt ^
  -c user_data/freq/freq_be.json ^
  --strategy HighFreq5mStrategy ^
  --strategy-path user_data/freq ^
  --timeframe 5m ^
  --timerange=20250720-20251024 ^
  --hyperopt-loss SharpeHyperOptLoss ^
  --epochs 1000 ^
  --spaces buy sell roi stoploss ^
  --random-state 42 ^
  --min-trades 30 ^
  -j -1
```

#### 完整优化（10000次）
```cmd
.\user_data\freq\hyperopt_be.bat
```

---

### 步骤4：应用优化结果

优化完成后，freqtrade会自动生成最优参数JSON文件：
```
user_data/freq/HighFreq5mStrategy.json
```

重新运行回测验证：
```cmd
.\user_data\freq\backtest_be.bat
```

### 问题2：FGI数据加载失败
```
不影响回测，FGI只是辅助指标
默认值会设为50（中性）
```

### 问题3：数据不足
```
解决：下载更多历史数据
python freqtrade/main.py download-data ^
  -c user_data/freq/freq_be.json ^
  --timeframe 5m ^
  --days 500 ^
  --trading-mode futures
```

### 问题4：优化太慢
```
解决方案：
1. 减少epochs（如1000->500）
2. 减少优化空间（只优化buy和sell）
3. 减少币种（只用BTC/ETH）
4. 使用更快的loss函数（OnlyProfitHyperOptLoss）
```
