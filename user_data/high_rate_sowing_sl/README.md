# 高倍率播种策略 - 支持做空版本 (HighRateSowingSL)

## 策略概述

基于原 HighRateSowing 策略的升级版本，支持双向交易（做多和做空）。

### 核心特性

- **时间周期**: 分钟级别 (1m)
- **交易模式**: 合约 (futures)
- **保证金模式**: 逐仓 (isolated)
- **杠杆倍数**: 20倍
- **最大持仓**: 3个合约
- **持仓模式**: 单向持仓（同一时间只持有多仓或空仓）

### 做空逻辑

#### 买入信号时
- **有空仓** → 先平空仓，再判断是否开多仓
- **无空仓** → 直接开多仓

#### 卖出信号时
- **有多仓** → 先平多仓，再判断是否开空仓
- **无多仓** → 直接开空仓

### 信号来源

#### 做多信号 (enter_long)
- 条件1: 从最高点下跌超过阈值
- 条件2: 单根K线涨幅或连续3根K线上涨
- 条件3: 图形反转（大跌后反弹）
- 条件4: 震荡行情支撑位反弹
- 条件5: 简单上涨趋势入场

#### 做空信号 (enter_short)
- 条件1: 双顶检测
- 条件2: 压力位附近 + 下降趋势

### 止损机制

#### 多仓止损
- 当价格低于支撑价格 X% 时触发止损

#### 空仓止损
- 当价格高于压力价格 X% 时触发止损

## 与原策略的区别

| 特性 | HighRateSowing | HighRateSowingSL |
|------|---------------|-----------------|
| 做空支持 | ❌ 仅做多 | ✅ 支持做空 |
| can_short | False | True |
| enter_short | 无 | 有 |
| exit_short | 无 | 有 |
| 持仓模式 | 单向做多 | 单向多空 |

## 使用方式

1. 将 `HighRateSowingSL.py` 复制到 freqtrade 策略目录
2. 创建配置文件，设置 `trading_mode: futures`
3. 运行回测或实盘

```bash
# 回测示例
freqtrade backtesting --strategy HighRateSowingSL --config config.json
```

## 注意事项

- 确保交易所支持合约交易
- 确保配置了正确的保证金模式和杠杆
- 建议先进行充分回测再实盘使用
